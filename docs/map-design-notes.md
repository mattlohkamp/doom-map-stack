**No symmetrical monster placement** \- if you enter into a room, there should not be a monster in all four corners, there should not be one monster on the left and one on the right, there should not be two precisely mirrored groups of soldiers. Monsters should be used in varying numbers groups, and placement.

**Key doors and key locations should be visually marked** \- blue doors and blue switches should be visually obvious, and so should the blue key location \- you should be able to catch glimpses of the key before you get to it \- you should see the key location marked in decorative blue, to associate the upcoming key color.

**Monsters need pathing and alternate pathing** \- avoid ‘monster turrets’ aka monsters unable to leave their starting position to chase the player. Playtest monster encounters to verify that aggroed monsters can pathfind to the player from a significant distance, multiple rooms, etc. encourage monsters to split, some to rush the other while others flank \- provide multiple routes in and out of big encounters, and possibly elements that break the ‘easy’ path so monster wander off around the corner and come at the player from behind.

**Pickups that trigger an appropriate encounter should be rare** \- every rocket launcher you pick up should not set off a rock launcher oriented encounter. The exception to this is temporary powerups like berserk, invulnerability, invisibility, etc \- these should be telegraphed, visually previewed, so that when the encounter starts, the user knows to run to grab the right powerup. Don’t just give the BFG to the player, then immediately spawn in a BFG-level mob of enemies.

**Monster ambushes should rarely feel unfair** \- don’t just teleport in as much shit as you can. Send them in waves, show the player the information they need to adapt their strategy as the encounter progresses.

**Let players see traps before they fall into them** \- let them know to be careful, and use consistent presentation so hitting a trap feels like their own fault for not being more cautious, not like an unfair gotcha. Additionally \- traps should not be autokills.

**Teleportation should not be a mystery** \- if possible let player see monster use teleporter first, let player catch glimpse of teleport destination before entering origin, and use consistent visual marking to signpost each end.

**Switches should control visible elements** \- the user should never have to do more than briefly glance around to see what effect the switch has, and the user should NEVER have to wonder about what a timed switch did, except in very exceptional secret cases.

**No one-way lifts, no close-only doors \-** every gate should be re-triggerable via switch. It’s okay to put the switch in a location that requires the user to clear monsters in a trap before accessing it.  
**No bottomless pits** \- see no one-hit-kill traps

**No inescapable pits** \- all pits should come with lifts, doors, teleporters, etc, that return the user to the top. Pit escapes are an okay place to hide bonuses and/or shortcuts, but probably not secrets, and definitely not main paths through the level.

**No out-of-view hitscanners, and always provide cover** \- the user should never think “what’s hitting me?” It should always be obvious where the enemy is shooting them from. Projectiles make this easy, hitscans make this hard.

**Encourage monster infighting** \- whenever possible, monsters should be grouped to allow for the possibility of infighting \- remember, “Demonic monsters of most species are immune to their own kind's projectile attack.” Chaingunner’s normally unfair hitscan snipe can be slightly mitigated by encouraging friendly fire opportunities.

**Cover height should be obvious** \- players should never have to guess about whether cover is high enough to block enemy’s attacks

**Avoid extreme verticality** \- even though source ports will mostly accommodate it, players should rarely if ever have to look up or down. At most, they should be recentering their aim, not craning their neck up or down to figure out what to do next.

**Delivery weapons on-tempo** \- if doing a multi stage campaign, one new weapon per map, with a map that provides proper ammo and showcases weapon capabilities versus different monsters. Encourage situations where players use ‘non traditional’ weapon vs monster machups.

**Give players a break** \- let them have some fun. Give them a pack of little guys that are easy to chaingun down or blast through with rockets or barrels. Drop in a couple pain elementals, then let them go crazy with a fully charged plasma gun.

**Establish visual patterns, then break them to mark secrets** \- one misaligned wall texture, or novel texture variant, or wrong woodgrain or tile or stonework, inset, light effect / flicker, missing element, etc etc

**Use doors & lifts that monsters will operate** \- apart from some switches, the player should not be in sole control of gates. Monsters should be able to path \+ pursue through gates.

**Necessary temporary items should respawn** \- this includes biosuit, invulnerability, etc \- anything that’s required to make it through a sequence without taking damage. If taking damage is required, respawning healing items is required. If dealing damage is required, respawning ammo is required. The player should never encounter a ‘soft-lock’ state that requires them to start the level over due to running out of a resource.
