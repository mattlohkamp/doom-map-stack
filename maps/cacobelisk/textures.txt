// The hall's sky (map.toml's sky). Note #70 (2026-11-23): Freedoom's cloud sky SKY3 (red clouds on black),
// "darkened and tinted all green": a black ground, and over it the clouds turned to green (the engine's
// Green translation: brightness kept, colour replaced) at 60% strength. (Note #65 before it: the
// starfield SKY4 with its red and blue halved: Patch "SKY4", 0, 0 { Blend "80FF80" }.)
WallTexture "CACOSKY", 512, 128
{
	// Notes #104, #105 (2026-11-24): "make the sky dark like the walls": blended 80% towards the hall's fog colour
	// (0x0A160E, what its far walls fade to), so wall and sky nearly meet; the clouds still show faintly. The
	// number is how far (0 = the bright green clouds of before).
	// (First as one patch with both Translation and Blend: the engine kept only the Blend, and the sky came out
	// dark red. So two layers: the green clouds, and over them the same picture as one flat colour, 80% opaque.)
	Patch "P-SKY3", 0, 0 { Translation "Green" }
	// Note #110: the aim is that the dark walls look like the sky's dark clouds, so the clouds must keep their
	// light and dark: the layer over them is near black now (it only darkens), 70% opaque. Measured in the
	// mapper's screenshot: far walls (7, 11, 8); the 80% fog-colour layer gave a flat (15, 25, 15), twice as light
	// and without clouds. With this the sky should run from about (3, 5, 4) to (17, 19, 10) round the walls' colour.
	// Note #113: "the sky is olive drab, the wall almost a dark cyan green". Measured in the shot: sky (12, 17, 11),
	// far wall (6, 12, 8): too light and too yellow. A stronger layer (85%) of a dark cyan-green: worked out so
	// the sky where the mapper looked comes to the wall's (6, 12, 8); the clouds are fainter for it.
	Patch "P-SKY3", 0, 0 { Blend "#000604", 1.0 Style Translucent Alpha 0.85 }
}
